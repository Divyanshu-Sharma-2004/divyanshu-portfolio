# Divyanshu Sharma — Portfolio

A personal portfolio website built with Next.js, React, and TypeScript. The repository also includes a standalone `index.html` version.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` to view the site.

## Build

```bash
npm run build
```

## Project structure

- `src/app/` — Next.js page, components, and global styles
- `public/` — portrait, resume, and skill icons
- `index.html` — standalone portfolio page
