# Divyanshu Sharma — Portfolio

A personal portfolio for Divyanshu Sharma, focused on quality assurance, manual testing, and LLM application testing. The site presents skills, work experience, projects, education, and contact information. It is built as a Next.js application and the repository also contains a standalone HTML version.

## Run locally

### Requirements

- Node.js (LTS recommended)
- npm (included with Node.js)

Open a terminal in the project folder (`D:\Portfolio` on this machine), then install the dependencies:

```powershell
npm.cmd install
```

Start the development server:

```powershell
npm.cmd run dev
```

In PowerShell, `npm.cmd` avoids the script execution policy error that can occur when PowerShell tries to run `npm.ps1`. In Command Prompt or a terminal where `npm` works, use `npm install` and `npm run dev` instead.

Open [http://localhost:3000](http://localhost:3000). Leave the terminal running while you use the site; press `Ctrl+C` there to stop the server.

## Available commands

| Command | Description |
| --- | --- |
| `npm run dev` | Start the Next.js development server. |
| `npm run build` | Create a production build. |
| `npm run start` | Serve the production build; run `npm run build` first. |
| `npm run lint` | Check the project with ESLint. |

In PowerShell, prefix these with `npm.cmd` if `npm` is blocked by the execution policy.

## Tech stack

- **Next.js 15** with the App Router
- **React 19**
- **TypeScript 5** with strict type checking
- **CSS** for the portfolio layout, responsive styling, themes, and animations
- **Tailwind CSS 4** through its PostCSS plugin
- **ESLint 9** with the Next.js Core Web Vitals and TypeScript configurations
- Google Fonts: **Inter** and **Roboto**

## Site features

- Responsive navigation and project carousel with category filters
- Skills, work experience, projects, education, and contact sections
- Light and dark themes, with the selected theme saved in local storage
- Downloadable resume and portrait image
- Contact form that opens a prefilled Gmail compose window on desktop or the default mail app on mobile; it does not submit to a server
- Standalone `index.html` version of the portfolio

## Project structure

```text
.
├── public/
│   ├── skill-icons/          # Custom SVG skill illustrations
│   ├── Divyanshu.png         # Portfolio portrait
│   └── Divyanshu_resume.pdf  # Downloadable resume
├── src/
│   └── app/
│       ├── contact-section.tsx  # Contact links, form, and footer
│       ├── globals.css          # Global styles, themes, and responsive layout
│       ├── hero-headline.tsx    # Animated hero heading
│       ├── layout.tsx           # Root layout and page metadata
│       ├── page.tsx             # Main page content and portfolio data
│       ├── project-carousel.tsx # Filterable, responsive project carousel
│       ├── site-header.tsx       # Navigation and mobile menu
│       ├── skill-grid.tsx        # Skills display
│       └── theme-toggle.tsx      # Light/dark theme control
├── index.html                # Standalone HTML portfolio
├── package.json              # Scripts and dependency declarations
├── package-lock.json         # Locked npm dependency versions
├── next.config.ts            # Next.js configuration
├── postcss.config.mjs        # Tailwind CSS PostCSS plugin
├── eslint.config.mjs         # ESLint configuration
└── tsconfig.json             # TypeScript configuration and path alias
```

The `.next/` directory is generated by Next.js during development and builds. `node_modules/` contains installed dependencies; both are recreated locally and are not application source files.

## Updating portfolio content

- Edit the experience, project, education, and page text in `src/app/page.tsx`.
- Update skills in `src/app/skill-grid.tsx` and add custom SVGs under `public/skill-icons/` when needed.
- Replace the portrait or resume in `public/` while keeping the referenced filenames, or update the corresponding paths in the app.
- Adjust layout, colors, and responsive styles in `src/app/globals.css`.
- Update contact addresses and form behavior in `src/app/contact-section.tsx`.
